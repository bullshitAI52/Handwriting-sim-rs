# Handwriting-sim-rs

Handwriting-sim-rs is a cross-platform handwriting simulation tool built with Tauri, Vue, and Rust. It supports region selection, multi-page document backgrounds, handwriting variation, typo simulation, and PDF export.

## Usage

Install the development dependencies, start the Tauri application, choose a background or document, select the writing area, and export the generated pages to PDF. See the main README for platform-specific build instructions.
